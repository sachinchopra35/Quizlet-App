# App Store materials — Simple Punjabi

Copy, legal pages, and submission checklists for the iOS App Store listing.

| File | Purpose |
|------|---------|
| [checklist.md](checklist.md) | Step-by-step: what to submit where |
| [listing.md](listing.md) | App Store Connect fields (name, description, keywords, etc.) |
| [privacy-policy.md](privacy-policy.md) | Host at a public URL — required by Apple |
| [support.md](support.md) | Host at a public URL — required by Apple |
| [review-notes.md](review-notes.md) | Paste into App Review Notes when submitting |

The live site is **`docs/index.html`** in this repo. Full walkthrough: **[docs/github-pages-setup.md](../../docs/github-pages-setup.md)**.

**URLs for App Store Connect** (use the same link for Privacy and Support):

```
https://sachinchopra35.github.io/Quizlet-App/
```

Source copies for editing: [privacy-policy.md](privacy-policy.md) and [support.md](support.md) — keep `docs/index.html` in sync if you change them.

## Git

These files are **tracked in git** on purpose. They contain no secrets (your support email is already in the app). Version control lets you see exactly what you submitted with each release.
